# Feature Roadmap

Planned features for Deepen, tracked here so we can tackle them one by one.

## Content Capture & Organization
- [ ] Tags/labels system for captures (beyond just folders and bookmarks)
- [ ] Bulk operations (multi-select, batch move/delete/tag)
- [ ] Import/export (Notion, Pocket, Instapaper, browser bookmarks)
- [ ] Nested collections (sub-folders — model already has `parentCollection`)

## AI & Brain Chat
- [ ] Auto-categorization of new captures using AI *(up next)*
- [ ] Conversation sharing/export
- [ ] Follow-up suggestions after AI responses
- [ ] Citation linking (click source reference → jump to original capture)

## Search & Discovery
- [ ] Full-text search with filters (date range, source, format, collection)
- [ ] "Related captures" suggestions on the detail view
- [ ] Smart collections (auto-populated based on rules/queries)

## Collaboration & Sharing
- [ ] Public/shared capture links
- [ ] Workspace/team support (Capture model already has a `workspace` field)

## UX & Polish
- [ ] Keyboard shortcuts throughout the app
- [ ] Drag-and-drop for organizing captures into collections
- [ ] Reading progress tracking
- [ ] Mobile-responsive improvements

## Infrastructure
- [ ] Test suite setup (unit + integration)
- [ ] Offline support / PWA capabilities
